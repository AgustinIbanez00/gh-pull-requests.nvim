*gh-pr.txt*    gh-pr plugin

GH-PR is a Neovim plugin to review GitHub pull requests in-editor using the
GitHub CLI as backend.

Requirements
============

- `gh` installed and authenticated
- inside a git repository

Optional UI backends:

- `neo-tree.nvim` (primary)
- `telescope.nvim` (fallback)
- `snacks.nvim` (required for interactive overview)

Commands
========

:GhPrOpen
    Opens the pull request UI. Uses Neo-tree source `gh_pr` when available,
    otherwise falls back to Telescope if enabled.

:GhPrList
    Opens Telescope query and pull request picker.

:GhPrTelescope
    Opens Telescope query and pull request picker (fallback entrypoint).

:GhPrTelescopeActions
    Opens contextual Telescope actions:
      - active Review context when available
      - otherwise active PR context
      - otherwise falls back to query/PR picker

:GhPrTelescopeReview
    Opens Telescope actions scoped to active PR Review context.

:GhPrComments [number]
    Opens the PR Review source with comments integrated for the active PR
    or provided PR number.

:GhPrStartReview [number]
    Starts review flow for active/provided PR and opens PR Review source.
    Notification prompt (`Notify GitHub that review started...`) is shown
    only when:
      - PR is not authored by current user
      - current user is explicitly requested reviewer on that PR
      - current user has no pending review on GitHub yet

:GhPrReviewTree
    Toggles PR Review source (`gh_pr_review`).
    PR Review source sections: Overview, Labels, Files, Reviewers,
    Commits, Checks, Comments.
    In `Commits`, `<CR>` expands selected commit and lists changed files.
    In commit file nodes, `<CR>` opens diff scoped to selected commit
    (`parent[1] -> commit`).
    `Comments` is rendered as tree sections: `By File` and `Global`.
    `By File` groups threads by path/file and uses status badges:
    `[UNRESOLVED]`, `[RESOLVED]`, `[CLOSED]`.
    `Global` includes review events and general PR comments.
    In `Files`, directory nodes show `X/Y VIEWED` in yellow when at least
    one descendant file is viewed (recursive count including subfolders).
    Marking viewed/unviewed from `gh_pr_review` does not force-focus
    the `gh_pr` panel.
    Inside `gh_pr_review`, `R` forces refresh from GitHub for active PR.
    `r` re-runs start-review flow for selected PR context.
    `ra` submit pending review as approve.
    `rc` submit pending review as comment.
    `rr` submit pending review as request changes.
    `rd` discard pending review.
    `a` opens assignees edit dialog.
    `l` opens labels multi-select edit dialog.
    `u` opens reviewers multi-select edit dialog.
    `c` publish regular PR comment (`gh pr comment`) outside pending review.
    `x` toggles PR Review source from current context.
    `zA` expand all review nodes.
    `za` collapse all review nodes.
    `zF` expand `Files` subtree.
    `zf` collapse `Files` subtree.
    `zV` expand paths that contain viewed files.
    `zv` collapse paths that contain viewed files.
    `zC` expand `Comments > By File`.
    `zc` collapse `Comments > By File`.
    `zG` expand `Comments > Global` (including subgroups).
    `zg` collapse `Comments > Global` (including subgroups).
    `:GhPrOpenCommitPatch` opens the full patch for selected commit.

:GhPrRefresh
    Refreshes PR data in active views.

:GhPRReviewRefresh
    Forces PR Review refresh in background for the active review PR.
    Alias: `:GhPrReviewRefresh`.

:GhPrOverview
    Opens an interactive tabs overview for the active pull request.
    Requires `snacks.nvim`; if missing, an explicit error is shown.

:GhPrOverviewRefresh
    Refreshes the current overview buffer in place.

:GhPrOverviewMore {section} [count]
    Loads more items in a section (`checks`, `commits`, `timeline`).

Overview buffer keymaps:
    `a` approve review
    `d` request changes
    `c` comment review
    `m` merge PR
    `k` checkout PR branch
    `R` refresh overview
    `b` open PR URL in browser
    `C` open Comments PR tree for current PR
    `q` close buffer
    `H`/`L` previous/next tab
    `1..9` jump to tab
    `et` edit title
    `eb` edit description
    `el` edit labels (multi-select, replacement mode)
    `er` edit reviewers (multi-select, replacement mode; users + teams)
    `ea` edit assignees (comma-separated, replacement mode)
    `em` edit milestone (empty input removes milestone)
    `es` change state (`open`/`closed`)
    `ed` toggle draft status (`ready`/`draft`)
    `<CR>` open selected row action
    `<CR>` on `Commits` opens commit diff details in virtual patch buffer
    `gp` preview markdown link under cursor in PR description
    `gr` load more for current section tab
    `D` open diff for selected row (file/commit)
    `O` open original for selected file row
    `M` open modified for selected file row
    `,x` toggle PR Review source
    Every overview edit asks confirmation before execution and refreshes
    the overview on success.
    In multi-select edits (`labels`/`reviewers`), deselected current items
    are interpreted as removals.
    PR description is rendered inline as markdown in `Summary`.
    Markdown links in description render as labels and support preview.
    Link preview download is only used for GitHub attachments.
    Non-attachment links prompt `open link`/`cancel` and open in browser
    only after confirmation.
    Overview markdown normalizes CRLF/LF line endings to avoid `^M`
    artifacts on Windows.
    PR metadata (state/review/merge/branches/stats) is rendered globally
    in header across tabs.
    `Summary` no longer renders the old `Actions` block.

:GhPrCheckout [number]
    Runs `gh pr checkout` for the active PR or provided number.

:GhPrOpenDiff
    Opens active file as virtual PR diff using configured render mode:
    vertical split, horizontal split, or unified inline.
    Image files (`png/jpg/jpeg/gif/webp/bmp/svg`) are rendered as previews
    in virtual buffers when `snacks.image` is available.
    If configured mode is `unified` for an image file, gh-pr forces split
    layout (vertical/horizontal) for base/head preview.
    If image rendering is unavailable/unsupported, fallback behavior is
    controlled by `diff_view.images.fallback_mode`:
      - `menu` opens a custom buffer with fallback actions
      - `metadata_only` renders metadata text diff in the current buffer
      - `auto_local` opens local cached image(s), then metadata fallback
      - `auto_github` opens GitHub compare URL, then metadata fallback
    If GitHub file content cannot be loaded, command fails with an explicit
    error (no implicit patch fallback buffer).
    Virtual file content normalizes CRLF/LF/CR endings to avoid `^M` artifacts.
    Diff actions are namespaced under `<localleader>` to avoid overriding
    native Neovim default keys.
    In virtual PR buffers, `<localleader>dk` opens a modal floating window with comments
    for the current line.
    Press `<localleader>dr` to refresh current diff buffer from GitHub.
    Press `<localleader>d?` to open a floating shortcuts help dialog for this buffer.
    Press `<localleader>dq` for quick close:
      - in 2-way diff closes head/modified window and keeps base/original
      - in single-buffer views closes current buffer and opens PR Review
    Press `<localleader>dQ` to close current diff view(s) and open/focus PR Review.
    On first open per diff buffer, gh-pr shows a one-time hint with close shortcuts.
    Additional virtual-buffer shortcuts:
      `<localleader>dr` refresh current diff from GitHub
      `<localleader>dq` quick close
      `<localleader>dQ` close diff view(s) and open PR Review
      `<localleader>tw` toggle whitespace diff mode (ignored/strict)
      `<localleader>ts` toggle leading/trailing whitespace/tab symbol rendering
      `<localleader>te` toggle endline markers (`LF`/`CRLF`/`CR`)
      `<localleader>mm` cycle diff mode
      `<localleader>mv` force vertical split mode
      `<localleader>mh` force horizontal split mode
      `<localleader>mu` force unified mode
      `<localleader>ic` add inline comment at cursor (`MODIFIED`/head or `unified`)
      visual `<localleader>ic` add inline comment for selected range (`v`/`V`, head or `unified`)
      `<localleader>is` add inline suggestion at cursor (`suggestion` template)
      visual `<localleader>is` add inline suggestion for selected range (`v`/`V`)
      image files disable `<localleader>dk`, `<localleader>ic`, `<localleader>is`, `<localleader>dn`, `<localleader>dp` and whitespace/layout toggles
      image files: `<localleader>io` runs default fallback action, `<localleader>im` opens fallback menu
      for `ADDED` files, opens single MODIFIED buffer (no split/unified layout)
      in `ADDED` single mode, `<localleader>ic` is allowed on any line/range
      inline comments are validated before opening composer:
      - head: only inside diff hunks
      - unified: only on added (`+`) lines
      composer: `<C-s>` submit draft, `q`/`<Esc>` cancel
      `<localleader>dn` next change
      `<localleader>dp` previous change
      `<localleader>df` next file
      `<localleader>dF` previous file
      `<localleader>dv` next reviewed file
      `<localleader>dV` previous reviewed file
      file navigation always reopens full diff view using current render mode
      (`vertical`/`horizontal`/`unified`)
      `<localleader>rc` submit pending review as comment
      `<localleader>ra` submit pending review as approve
      `<localleader>rr` submit pending review as request changes
      `<localleader>rd` discard pending review
      `<localleader>rx` toggle PR Review source

:GhPrOpenOriginal
    Opens virtual readonly base version for active PR file.

:GhPrOpenModified
    Opens virtual readonly head version for active PR file.

:GhPrOpenCommitPatch
    Opens full patch for selected commit in virtual readonly buffer.

:GhPrToggleReviewed
    Toggles local viewed state for the current PR file.

:GhPrNextChange
    Jump to next diff hunk.

:GhPrPrevChange
    Jump to previous diff hunk.

:GhPrApprove
    Prompt review message and confirm before submitting approve review.

:GhPrRequestChanges
    Prompt review message and confirm before submitting request-changes review.

:GhPrComment
    Prompt review message and confirm before submitting general comment review.

:GhPrReviewSubmit
    Submit current pending review as comment (message + confirm).

:GhPrReviewApprove
    Submit current pending review as approve (message + confirm).

:GhPrReviewRequestChanges
    Submit current pending review as request changes (message + confirm).

:GhPrReviewDiscard
    Discard current pending review (confirm).

:GhPrMerge [merge|squash|rebase]
    Merge active PR with selected strategy.

:GhPrQueryAdd
    Add query definition (folder/label/query).

:GhPrQueryEdit
    Edit existing query definition.

:GhPrQueryDelete
    Delete existing query definition.

Keymaps
=======

<leader>gho       Open PR UI (:GhPrOpen)
<leader>ghl       Open Telescope list (:GhPrList)
<leader>ghm       Open comments tree (:GhPrComments)
<leader>ghx       Toggle PR Review source (:GhPrReviewTree)
<leader>ghr       Refresh (:GhPrRefresh)
<leader>ghv       Open PR overview (:GhPrOverview)
<leader>ghc       Checkout PR (:GhPrCheckout)
<leader>ghd       Open diff (:GhPrOpenDiff)
<leader>ght       Toggle viewed (:GhPrToggleReviewed)
<leader>ghn       Next diff hunk (:GhPrNextChange)
<leader>ghp       Previous diff hunk (:GhPrPrevChange)
gh_pr PR nodes     Expose only `Overview` child (no `Files` subtree)
`r` (gh_pr)      Start review flow for selected PR
`ra` (gh_pr)     Approve review flow for selected PR
`rc` (gh_pr)     Comment review flow for selected PR
`rr` (gh_pr)     Request-changes review flow for selected PR
`rd` (gh_pr)     Discard pending review for selected PR
`m` (gh_pr)      Merge flow for selected PR
`k` (gh_pr)      Checkout selected PR branch
gh_pr PR rows     Show `[DRAFT]` suffix and draft highlight when draft
`r` prompt rule   Ask `Notify GitHub...` only for eligible reviewer flow
`b` (gh_pr)      Open selected PR in browser (PR nodes only)
`b` (gh_pr_review) Open selected PR in browser (PR context nodes only)
`T` (gh_pr_review) Open Telescope actions scoped to Review context
`r` (gh_pr_review) Start/re-enter review flow
`ra`/`rc`/`rr`/`rd` (gh_pr_review) Submit/discard pending review
`a`/`l`/`u` (gh_pr_review) Edit assignees/labels/reviewers
`c` (gh_pr_review) Publish regular PR comment (`gh pr comment`)
`<space>` (gh_pr/gh_pr_review) Not bound by default (keeps `<leader>` free)
PR sources prioritize PR-specific mappings over generic Neo-tree mappings

Persistence
===========

- Queries: `stdpath("state")/gh-pr/queries.json`
- Viewed files: `stdpath("state")/gh-pr/state.json`
- Diff view prefs (`mode`, `ignore_whitespace`, `render_whitespace`, `render_endlines`): `stdpath("state")/gh-pr/state.json`
- Image fallback default action: `stdpath("state")/gh-pr/state.json`
- PR cache: `stdpath("state")/gh-pr/pr_cache.json`
- Cache is stored per source/repo key (`gh_pr` and `gh_pr_review`).
