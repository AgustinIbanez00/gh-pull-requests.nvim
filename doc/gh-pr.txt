*gh-pr.txt*    gh-pr plugin

GH-PR is a Neovim plugin to review GitHub pull requests inside the editor.

The functionality is under active development. It requires the GitHub CLI and
must be used from inside a git repository.

Commands
========

:GhPrList
    Displays open pull requests for the authenticated user in a Telescope
    picker. Each entry shows the pull request number, title, review state,
    and reviewer statuses. Selecting a pull request opens another picker with
    the files changed in that pull request. Choosing a file will download the
    base and head versions and display them side-by-side in diff mode. Buffers
    retain the original filetype so syntax highlighting and plugins are loaded.

:GhPrToggleReviewed
    Toggles a marker in the statusline of the current buffer indicating whether
    the file has been reviewed.

:GhPrNextChange
    When viewing a pull request file in diff mode, jump to the next change hunk.

:GhPrPrevChange
    When viewing a pull request file in diff mode, jump to the previous change
    hunk.

Keymaps
=======

The plugin defines default mappings that begin with `<leader>gh`:

    <leader>ghl       List pull requests (:GhPrList)
    <leader>ght       Toggle reviewed flag (:GhPrToggleReviewed)
    <leader>ghn       Next change hunk (:GhPrNextChange)
    <leader>ghp       Previous change hunk (:GhPrPrevChange)
