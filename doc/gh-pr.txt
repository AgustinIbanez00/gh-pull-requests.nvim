*gh-pr.txt*    gh-pr plugin

GH-PR is a Neovim plugin to review GitHub pull requests in-editor using the
GitHub CLI as backend.

Requirements
============

- `gh` installed and authenticated
- inside a git repository

Optional UI backends:

- `neo-tree.nvim` (primary)
- `telescope.nvim` (fallback)
- `snacks.nvim` (required for interactive overview)

Commands
========

:GhPrOpen
    Opens the pull request UI. Uses Neo-tree source `gh_pr` when available,
    otherwise falls back to Telescope if enabled.

:GhPrList
    Opens Telescope query and pull request picker.

:GhPrComments [number]
    Opens a comments tree (Problems-like) for the active PR or provided
    PR number. Selecting a line/comment node navigates to file + line.
    In `gh_pr_comments`: `p` previews in right split, `<CR>` opens.
    Long threads open a focused floating buffer; navigate with normal
    motions and close with `q`/`<Esc>`.

:GhPrRefresh
    Refreshes PR data in active views.

:GhPrOverview
    Opens an interactive tabs overview for the active pull request.
    Requires `snacks.nvim`; if missing, an explicit error is shown.

:GhPrOverviewRefresh
    Refreshes the current overview buffer in place.

:GhPrOverviewMore {section} [count]
    Loads more items in a section (`checks`, `commits`, `timeline`).

Overview buffer keymaps:
    `a` approve review
    `d` request changes
    `c` comment review
    `m` merge PR
    `k` checkout PR branch
    `R` refresh overview
    `o` open PR URL in browser
    `C` open Comments PR tree for current PR
    `q` close buffer
    `H`/`L` previous/next tab
    `1..9` jump to tab
    `et` edit title
    `eb` edit description
    `el` edit labels (comma-separated, replacement mode)
    `er` edit reviewers (comma-separated, replacement mode)
    `ea` edit assignees (comma-separated, replacement mode)
    `em` edit milestone (empty input removes milestone)
    `es` change state (`open`/`closed`)
    `ed` toggle draft status (`ready`/`draft`)
    `<CR>` open selected row action
    `<CR>` on `Commits` opens commit diff details in virtual patch buffer
    `gr` load more for current section tab
    `D` open diff for selected row (file/commit)
    `O` open original for selected file row
    `M` open modified for selected file row
    Every overview edit asks confirmation before execution and refreshes
    the overview on success.
    PR description is rendered inline as markdown in `Summary`.

:GhPrCheckout [number]
    Runs `gh pr checkout` for the active PR or provided number.

:GhPrOpenDiff
    Opens active file as virtual base/head side-by-side diff.
    In virtual PR buffers, `K` opens a modal floating window with comments
    for the current line.
    Additional virtual-buffer shortcuts:
      `,n` next change
      `,p` previous change
      `,f` next file
      `,F` previous file
      `,v` next reviewed file
      `,V` previous reviewed file

:GhPrOpenOriginal
    Opens virtual readonly base version for active PR file.

:GhPrOpenModified
    Opens virtual readonly head version for active PR file.

:GhPrToggleReviewed
    Toggles local viewed state for the current PR file.

:GhPrNextChange
    Jump to next diff hunk.

:GhPrPrevChange
    Jump to previous diff hunk.

:GhPrApprove
    Prompt review message and confirm before submitting approve review.

:GhPrRequestChanges
    Prompt review message and confirm before submitting request-changes review.

:GhPrComment
    Prompt review message and confirm before submitting general comment review.

:GhPrMerge [merge|squash|rebase]
    Merge active PR with selected strategy.

:GhPrQueryAdd
    Add query definition (folder/label/query).

:GhPrQueryEdit
    Edit existing query definition.

:GhPrQueryDelete
    Delete existing query definition.

Keymaps
=======

<leader>gho       Open PR UI (:GhPrOpen)
<leader>ghl       Open Telescope list (:GhPrList)
<leader>ghm       Open comments tree (:GhPrComments)
<leader>ghr       Refresh (:GhPrRefresh)
<leader>ghv       Open PR overview (:GhPrOverview)
<leader>ghc       Checkout PR (:GhPrCheckout)
<leader>ghd       Open diff (:GhPrOpenDiff)
<leader>ght       Toggle viewed (:GhPrToggleReviewed)
<leader>ghn       Next diff hunk (:GhPrNextChange)
<leader>ghp       Previous diff hunk (:GhPrPrevChange)
`C` (gh_pr)      Open comments tree (:GhPrComments)

Configuration
=============

Call `require("gh-pr").setup({ ... })` with:

- `remotes` (`{ "origin", "upstream" }` by default)
- `max_results` (`30`)
- `file_list_layout` (`"tree"` or `"flat"`, legacy fallback for `gh_pr`)
- `path_render.scope` (`"both"`, or `"files"` / `"comments"`)
- `path_render.mode` (`"compact"`, or `"tree"` / `"flat"`)
- `path_render.separator` (`"/"`, visual separator in compact mode)
- `path_render.show_status_prefix` (`true`, `Files` source only)
- `hide_viewed_files` (`false`)
- `line_comments.enabled` (`true`)
- `line_comments.keymap` (`"K"`)
- `line_comments.indicator_style` (`"sign_and_virtual_text"`)
- `line_comments.show_resolved` (`true`)
- `line_comments.show_outdated` (`true`)
- `line_comments.max_popup_width` (`90`)
- `line_comments.max_popup_height` (`18`)
- `line_comments.popup.enter` (`true`, modal popup on `K`)
- `line_comments.popup.position` (`"cursor"`, or `"editor"` / `"preview_window"`)
- `line_comments.popup.border` (`"rounded"`)
- `line_comments.popup.wrap` (`true`)
- `line_comments.popup.close_on_move` (`true`, only relevant for non-modal popup)
- `line_comments.popup.max_width|max_height` (`90|18`)
- `line_comments.virtual_text.enabled` (`true`)
- `line_comments.virtual_text.prefix` (`"C"`)
- `line_comments.virtual_text.show_count` (`true`)
- `line_comments.virtual_text.position` (`"eol"`, or `"inline"`)
- `line_comments.signs.open|resolved|outdated` (`"C>"`, `"C="`, `"C~"`)
- `line_comments.comments_tree.preview.keymap` (`"p"`)
- `line_comments.comments_tree.preview.position` (`"right"`)
- `line_comments.comments_tree.preview.keep_focus` (`true`)
- `overview.ui` (`"snacks"`)
- `overview.layout` (`"tabs"`)
- `overview.tabs` (`summary/checks/commits/timeline/files`)
- `overview.expand_step` (`20`)
- `overview.date_format` (`"%Y-%m-%d %H:%M"`)
- `overview.window.enabled` (`true`)
- `overview.window.border` (`"rounded"`)
- `overview.window.width_ratio|height_ratio` (`0.88`)
- `overview.window.min_width|min_height` (`100|28`)
- `overview.window.max_width|max_height` (`180|60`)
- `overview.window.backdrop` (`0`)
- `overview.window.enter` (`true`)
- `overview.theme.state_colors` (`true`)
- `overview.theme.checks_colors` (`true`)
- `overview.theme.labels` (`true`)
- `overview.theme.reviewers` (`true`)
- `overview.theme.timeline_kinds` (`true`)
- `overview.markdown.enabled` (`true`)
- `overview.markdown.provider` (`"auto"`)
- `overview.markdown.max_lines` (`500`)
- `overview.markdown.code_block_border` (`false`)
- `overview.max_items` (checks/commits/timeline)
- `overview.show` (toggle sections)
- `queries` list: `{ folder, label, query }`
- `ui.use_neotree` (`true`)
- `ui.telescope_fallback` (`true`)

Persistence
===========

- Queries: `stdpath("state")/gh-pr/queries.json`
- Viewed files: `stdpath("state")/gh-pr/state.json`
- PR cache: `stdpath("state")/gh-pr/pr_cache.json`
