*gh-pr.txt*    gh-pr plugin

GH-PR is a Neovim plugin to review GitHub pull requests inside the editor.

The functionality is under active development. It requires the GitHub CLI and
must be used from inside a git repository.

Commands
========

:GhPrList
    Displays open pull requests for the authenticated user in a Telescope
    picker. Each entry shows the pull request number, title, review state,
    and reviewer statuses. Selecting a pull request opens another picker with
    the files changed in that pull request. Choosing a file will download the
    base and head versions and display them side-by-side in diff mode. Buffers
    retain the original filetype so syntax highlighting and plugins are loaded.

:GhPrReviewTree
    Opens a sidebar tree listing the configured pull request queries. Use
    `<CR>` on a group to expand it and on a pull request to fetch its files.
    Files are prefixed with status icons (`+`, `~`, `-`, `>`) and are colour
    coded to match their Git status. Deleted entries are rendered with a
    strikethrough, and comment counts are shown alongside unresolved thread
    totals. Pressing `<CR>` on a file opens the side-by-side diff view.

    Expanding a pull request also opens a companion panel at the bottom of the
    screen that lists review comments grouped by file, similar to
    `trouble.nvim`. Comments display their line number, author, and a preview
    of the message. Unresolved threads are highlighted and outdated comments
    are annotated. Use `<CR>` on a comment to jump directly to the relevant
    line inside the diff view. The comment panel can be toggled like a tree,
    and `q` closes either the tree or the panel.

:GhPrToggleReviewed
    Toggles a marker in the statusline of the current buffer indicating whether
    the file has been reviewed.

:GhPrNextChange
    When viewing a pull request file in diff mode, jump to the next change hunk.

:GhPrPrevChange
    When viewing a pull request file in diff mode, jump to the previous change
    hunk.

Keymaps
=======

The plugin defines default mappings that begin with `<leader>gh`:

    <leader>ghl       List pull requests (:GhPrList)
    <leader>ght       Toggle reviewed flag (:GhPrToggleReviewed)
    <leader>ghn       Next change hunk (:GhPrNextChange)
    <leader>ghp       Previous change hunk (:GhPrPrevChange)

Configuration
=============

Use `require("gh-pr").setup()` to customise the plugin. The `queries`
parameter controls which pull request sections are shown in both the Telescope
picker and the side tree. Each entry must provide a `label` and a `query`.
Queries are executed through `gh search prs`, and the strings `${owner}`,
`${repository}`, and `${user}` are expanded to the current repository owner,
repository name, and authenticated GitHub login respectively. Additional keys
such as `limit`, `sort`, `order`, or `args` are appended to the GitHub CLI
command for more control. When `query` is set to `"default"`, the plugin falls
back to `gh pr list` for the current repository.

Example configuration:

>lua
require("gh-pr").setup({
  queries = {
    {
      label = "Waiting For My Review",
      query = "repo:${owner}/${repository} is:open review-requested:${user}",
    },
    {
      label = "Created By Me",
      query = "repo:${owner}/${repository} is:open author:${user}",
    },
    {
      label = "All Open",
      query = "repo:${owner}/${repository} is:open",
    },
  },
})
